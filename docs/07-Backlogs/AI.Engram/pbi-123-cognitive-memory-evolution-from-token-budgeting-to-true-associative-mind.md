# Task: Cognitive Memory Evolution: From Token Budgeting to True Associative Mind
**ID**: #123
**Target**: `src/BuildingBlocks/AI.Engram`
**Ref**: /src/BuildingBlocks/AI.Engram/README.md

## 📝 Description
### 1. Problem / Context
Current AI.Engram provides robust context lifecycle management (L1/L2 summary compression, eviction, and scoring), but still operates as a reactive token budgeting engine rather than a true cognitive memory system. Memory retrieval is purely passive, lacks subjective temporal perspective, misses autonomous offline reflection, and cannot turn past experiences into reusable procedural skills.

### 2. Proposed Changes
Establish the next-generation cognitive memory architecture for AI.Engram across 5 core pillars:
1. Associative Memory & Spreading Activation
2. Episodic Memory with Temporal & Emotional Dimensions
3. Autonomous Offline Reflection & Belief Updating
4. Procedural Memory for Tool & Workflow Policy Learning
5. Theory of Mind (ToM) & Perspective-Aware Social Memory

### 3. Acceptance Criteria
- [ ] Sub-epics and stories for the 5 cognitive pillars are defined and reviewed
- [ ] Integration points with AI.Psyche and VectorStore/GraphStore are specified
